# acme.py v1.0.0 — stable

Stable release of the TUI wizard for **locally-managed** WatchGuard Fireboxes over SSH (default port `4118`).

> **Cloud-managed Firebox?** Use WatchGuard Cloud instead. This tool is only for **locally-managed** Fireboxes.

## Included

- Auto-assesses the web server cert on connect: self-signed (Fireware CA) vs valid / expiring / expired, with expiry countdown.
- Issues: openssl key + CSR → `certbot` HTTP-01 (`--standalone` or `--webroot`, staging or production) → `.pfx` bundle with autogenerated 32-char password.
- Imports via Firebox CLI over a temporary built-in TFTP server (PEM files, chain order enforced, demanded root CAs auto-resolved, combined cert+key bundle when the box asks for the key) — or `.pfx` via Web UI/WSM.
- Selects the cert as web server cert (`configure` → `web-server-cert`, with confirmation) and verifies it is active.
- `--showonly` assessment mode, `--tui` interactive menu, and new `--version` flag (`acme.py 1.0.0`).
- Stdlib only — no pip deps. System binaries: `python3`, `ssh`, `openssl`, `certbot`.
- Linux tested; Windows via WSL2 with mirrored networking.

## Validation status

Tested end-to-end on Fireware 12.12.3. Single-FQDN HTTP-01 only — no wildcards (those need DNS-01, unsupported). IPv4 only. CLI import takes Base-64 PEM only (`.pfx` via Web UI/WSM).

Firebox CLI idle timeout is short — keep the TUI moving; every step is re-runnable and idempotent.

See [README Quick Start](../..//README.md#run) and SNAT / requirements in `README.md`.

## Install / Run

```bash
sudo apt install -y openssh-client openssl certbot
python3 acme.py --version
python3 acme.py --showonly
sudo python3 acme.py -u admin --tui
```

Source archives (`.zip` / `.tar.gz`) are attached to this GitHub Release automatically from the `v1.0.0` tag. No compiled binaries — run `acme.py` directly.
